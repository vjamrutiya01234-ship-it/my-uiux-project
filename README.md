# my-uiux-project
## Lumen landing page (demo)

A premium, responsive single-page marketing site built with the **ui-ux-pro-max** skill (`.claude/skills/ui-ux-pro-max/SKILL.md`).

- `site/index.html`, `site/styles.css`, `site/script.js`: plain HTML/CSS/JS with no build step. Open `site/index.html` in a browser.
- `design-system/lumen/MASTER.md`: the design system generated by the skill (colours, type, spacing, effects).

Regenerate the design system:

```bash
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "premium SaaS productivity landing" --design-system -p "Lumen" --variance 5 --motion 4 --density 3
```
